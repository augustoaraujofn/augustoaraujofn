## 👨‍💻 Sobre mim

Sou graduado em **Análise e Desenvolvimento de Sistemas** e atuo na área de **Quality Assurance (QA)**, com foco em contribuir para a qualidade, estabilidade e confiabilidade de aplicações.

Tenho experiência com testes manuais, testes funcionais e exploratórios, identificação e documentação de defeitos, além de projetos de automação de testes utilizando JavaScript.

Atualmente, estou aprofundando meus conhecimentos em automação com Cypress, testes de API com Postman e consultas SQL para validação de dados.

Acredito que qualidade vai além de encontrar defeitos: envolve compreender regras de negócio, antecipar riscos e colaborar com o time para entregar produtos que realmente atendam às necessidades dos usuários.
